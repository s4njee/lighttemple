## Ace of Spades demo

- `demos/ace-of-spades/eye-emblem.png` — an original Eye-of-Providence engraving
  authored for this repository. It replaces an earlier image whose provenance was
  not recorded. The motif itself (an eye in a triangle with rays) is public domain.
- `demos/ace-of-spades/fonts/ace-script-latin.woff2` — a Latin subset of **Yesteryear**
  by Brian J. Bonislawsky (Astigmatic), used under the SIL Open Font License 1.1
  (`fonts/OFL.txt`). A subset is a Modified Version under the OFL, so the reserved
  font name "Yesteryear" has been dropped: the name table now reads "Ace Script"
  (the code loads the family under that name). The original copyright notice is
  retained in the font.
